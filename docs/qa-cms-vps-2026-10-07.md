# Validasi CMS mandiri dan server VPS — 7 Oktober 2026

CMS Keystatic/GitHub dan adapter Cloudflare diganti dengan CMS username/password di `/admin` serta server Node standalone. Konten dan gambar tersimpan pada DATA_DIR yang persisten; penyimpanan tidak memerlukan build ulang.

## Hasil pengujian

- Build produksi Astro/Node dan validasi konten awal berhasil.
- Playwright: 23 tes lulus, mencakup website desktop/mobile, editor CMS, login, proteksi origin, konflik versi, validasi konten, profil dinamis, upload raster, penolakan SVG, logout dan penolakan penggunaan ulang sesi.
- Tes server Node: 1 tes lulus. Server dihentikan dan dijalankan kembali dengan DATA_DIR yang sama; konten, gambar, dan sesi tetap tersedia. Cookie Secure dan login melalui header reverse proxy HTTPS juga diperiksa, termasuk penolakan origin lain.
- Pengujian memakai penyimpanan sementara terisolasi dan akun khusus tes. Tidak ada akun atau password admin produksi yang dibuat.
- `.env`, DATA_DIR, dan file sesi tidak ikut repository. Contoh environment mengaktifkan cookie Secure; HTTP lokal memerlukan `CMS_COOKIE_SECURE=false`.

## Batas validasi

Pengujian dilakukan pada build produksi Node di Windows. Docker image dan deployment VPS belum dijalankan di lingkungan ini. Hasil ini memvalidasi alur yang diuji dan bukan audit keamanan menyeluruh.

Deployment memerlukan HTTPS, domain PUBLIC_SITE_URL yang sesuai, folder DATA_DIR permanen milik pengguna aplikasi, dan satu proses Node. Petunjuk tersedia di `docs/vps.md`.
