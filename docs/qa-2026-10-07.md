## Contrast decisions
- `#0F9E8E` on `#FAFAF7` is 3.19:1, so it's used for marks/fills only. Text and button fills use `#0B7A6E` (5.0:1).
- Animated demo text that fades is also `visibility: hidden` while invisible, so no low-contrast in-between state is exposed.
